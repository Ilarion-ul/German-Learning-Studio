# Початковий запит до Codex

Прочитай AGENTS.md і APP_DEVELOPMENT_PLAN.md. Працюємо над German Learning Studio — offline-first застосунком для Windows 11 на Qt 6 Quick/QML, C++20, CMake, SQLite.

Зараз виконай тільки **Task 01 (foundation)**:
1. Перевір наявний стан репозиторію й інструменти (Qt, компілятор, CMake, Ninja); не припускай, що все вже інстальоване.
2. Склади короткий план змін, потім створи мінімальний застосунок із shell-навігацією Today / Cards / Grammar / Course / Statistics.
3. Додай SQLite data layer із `schema_migrations` (мінімальна перша міграція), базові unit/smoke tests та точні Windows команди в README.
4. Збери і запусти всі доступні тести. Якщо збірка неможлива, явно назви відсутні залежності і наведи перевірені команди для локального запуску.
5. Не реалізовуй SRS/Anki/API у першому завданні; не змінюй жодну реальну базу Anki.

Наприкінці наведи перелік файлів, виконані команди, результати та конкретну пропозицію Task 02.
